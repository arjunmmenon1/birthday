# Annamee — Romantic Birthday Surprise Website

A responsive peach-and-cream birthday experience built with plain HTML, CSS, and JavaScript.

## Included
- Premium peach, cream, coral, and rose visual design
- Floating balloons, glowing gift, hearts, and reveal-on-scroll animations
- Birthday countdown with an editable date
- Photo memory gallery (select up to 6 images; images are only displayed locally in the browser)
- Interactive virtual cake: tap candles individually, blow out all candles, and cut the cake
- Confetti celebrations
- Animated envelope and birthday love letter
- Optional soundtrack button
- Responsive mobile layout

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. To add music, place a music file you own or are licensed to use in this folder and name it `music.mp3`.
4. Select the music button on the page to start playback (browsers require a user gesture).

## Customize
- **Birthday date:** use the date field in the countdown section. The default is October 12 (the next upcoming occurrence).
- **Letter:** edit the letter paragraphs inside `index.html`.
- **Name / wording:** search `Annamee` in `index.html` and edit as desired.
- **Photo memories:** use “Add your photos” on the page. Photos are not uploaded to a server.
- **Colors and fonts:** edit CSS variables near the top of `style.css`.

## Publish online
You can publish the extracted folder using a static hosting provider such as Netlify Drop or GitHub Pages. Upload the contents of the folder (not the ZIP itself) to your host.

## Notes
- This is a static front-end website; no server or installation is required.
- The letter and page content are visible in the source code. This is a romantic surprise page, not a secure/private messaging system.
- External Google Fonts are used when an internet connection is available; fallback fonts will be used offline.
